# Enterprise Network Monitoring and Security Analysis Dashboard

## Description

This project demonstrates enterprise network design, packet analysis, network performance monitoring, and security analysis using:
- Cisco Packet Tracer
- Wireshark / TShark
- Python
- Streamlit

The project combines an enterprise network simulated in Cisco Packet Tracer with real network traffic captured using Wireshark/TShark. Python is used to analyze the captured traffic and generate network performance, protocol, and security metrics, which are visualized through an interactive Streamlit dashboard.

## Project Objectives

- Design and configure an enterprise network
- Implement VLANs and inter-VLAN routing
- Configure network services such as DHCP, DNS, HTTP, FTP, and Email
- Implement basic network security using ACLs
- Capture and analyze network traffic using Wireshark/TShark
- Calculate network performance and reliability metrics
- Analyze protocols such as TCP, DNS, ARP, and ICMP
- Identify basic network security anomalies
- Visualize network information through an interactive dashboard
- Support both offline PCAP analysis and live network monitoring

## Key Features
