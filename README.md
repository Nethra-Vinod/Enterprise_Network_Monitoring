# Enterprise Network Monitoring and Security Analysis Dashboard

## Description

This project demonstrates enterprise network design, packet analysis, performance monitoring, and security analysis using:

- Cisco Packet Tracer
- Wireshark
- Python
- Streamlit

## Project Objectives

- Design an enterprise network
- Capture and analyze network traffic
- Calculate network performance metrics
- Detect basic security anomalies
- Visualize results using an interactive dashboard
